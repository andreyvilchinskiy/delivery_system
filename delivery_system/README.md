# Система учёта заказов "Быстрая доставка"

## Описание проекта

Внутреннее приложение для учёта заказов компании «Быстрая доставка». Позволяет управлять клиентами и заказами, формировать отчёты, экспортировать и импортировать данные.

## 1. Функциональные возможности

### 1.1 Управление клиентами (CRUD)
- **Создание** – добавление нового клиента с именем, телефоном и адресом
- **Чтение** – просмотр списка всех клиентов
- **Редактирование** – изменение данных клиента
- **Удаление** – удаление клиента (если у него нет заказов)

### 1.2 Управление заказами (CRUD)
- **Создание** – оформление заказа с выбором клиента и добавлением товаров
- **Чтение** – просмотр списка заказов с фильтрацией по статусу и дате
- **Редактирование** – изменение заказа (клиент, статус, состав товаров)
- **Удаление** – удаление заказа
- **Статусы заказов:** «новый», «в доставке», «выполнен», «отменён»

### 1.3 Отчёты и аналитика
- Количество заказов по статусам
- Топ-3 клиента по сумме заказов
- Общая выручка за период (день/неделя/месяц)

### 1.4 Экспорт / Импорт данных
- Экспорт заказов в JSON или XML формат
- Импорт заказов из JSON или XML файла
- Автоопределение формата по расширению файла
- Проверка корректности данных при импорте

### 1.5 Логирование
- Все действия записываются в лог-файлы
- Логи хранятся в папке `logs/` с разбивкой по датам
- Одновременный вывод в файл и консоль

## 2. Запуск приложения

### 2.1 Требования к системе
- Python 3.8 или выше
- SQLite3 (входит в состав Python)

### 2.2 Установка

# Склонируйте репозиторий
git clone <url-вашего-репозитория>
cd delivery_system

# Установите зависимости (только для тестов)
pip install -r requirements.txt

### 2.3 Запуск в GUI режиме
python main_gui.py

### 2.4 Запуск в CLI режиме
python main_cli.py report --period day      # Отчёт за день
python main_cli.py report --period week     # Отчёт за неделю
python main_cli.py report --period month    # Отчёт за месяц

# Команда export – экспорт заказов
python main_cli.py export --file orders.json    # Экспорт в JSON
python main_cli.py export --file orders.xml     # Экспорт в XML

# Команда import – импорт заказов
python main_cli.py import --file orders.json    # Импорт из JSON
python main_cli.py import --file orders.xml     # Импорт из XML

### 2.5 Запуск тестов
pytest tests/ -v
